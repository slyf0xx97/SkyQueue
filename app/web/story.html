How it works

The architectureone airport, start to finish

SkyQueue

Autonomous multi-agent AI for storm-delayed departure queues. Three AI agents coordinate tower, airline and ramp; plain code checks every plan; a person approves.

Data
  • 2015 US DOT flight delays (challenge dataset)
  • airports.csv, airlines.csv
  • Live weather: NOAA Aviation Weather Center
  • Simulated ops messages, gates and crew hours
Built with
  • Claude API: Pydantic
  • Python, pandas, pytest
  • OR-Tools CP-SAT
  • Streamlit, SQLite
  • Cloudflare Tunnel
