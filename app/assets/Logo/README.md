The SkyQueue mark, `skyqueue-mark.svg`: a navy tile (#0e1a28) carrying the hold-short line in taxiway yellow (#ffc400). The file draws its own tile, so it reads on both themes and on photos; it uses fixed colours and does not inherit text colour.

- Use as the Streamlit page icon, the favicon and on the title and closing slides. Minimum size 24 px.
- Leave a clear margin of one quarter of the tile width on every side. Do not recolour, outline, rotate or add a shadow.
- There is no wordmark file. Set the name "SkyQueue" in `display-xl` (Barlow Condensed 700) beside the mark.
